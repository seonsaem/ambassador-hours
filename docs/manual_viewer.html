1. 시스템 소개 및 시작하기

광운알리미 시간 관리 시스템은 우리 대학 입학홍보대사 단원들이 참여한 전공체험, 모의전형 행사, 부서별 콘텐츠 제작 시간을 간편하게 기록하고 인정받을 수 있도록 만든 전용 공간입니다. 컴퓨터는 물론 스마트폰에서도 앱처럼 편리하게 이용할 수 있습니다.

2. 회원가입과 최초 로그인

관리자에게 제출한 본인의 공식 이메일 주소로 본인 인증을 거쳐 가입을 진행합니다.

ambassador-hours.vercel.app/signup [그림 1] 회원가입 화면
화면 설명: 회원가입 페이지는 관리자가 사전에 등록해 둔 공식 이메일과 본인의 기수 및 실명을 입력하여 본인 인증 후 계정을 활성화하는 화면입니다.

2.1 회원가입 순서

  1. 인터넷 주소창에 회원가입 주소를 입력하고 접속합니다.
  2. 이메일 칸에 관리자에게 미리 알려준 구글 또는 네이버 이메일을 정확히 적습니다.
  3. 이름 칸에는 기수와 본인 실명을 한 칸 띄워서 적습니다. 예를 들어 15기 홍길동처럼 적어야 시스템에서 기수별로 시간이 정확히 분류됩니다.
  4. 비밀번호는 안전하게 6자리 이상으로 설정하고 아래 확인 칸에도 똑같이 입력합니다.
  5. 회원가입 버튼을 누르면 즉시 가입이 완료되고 자동으로 로그인됩니다.
⚠️ 가입 유의사항: 관리자가 미리 등록해 두지 않은 이메일로 가입을 시도하면 가입할 수 없다는 안내가 나타나므로, 이메일이 바뀌었거나 가입이 안 될 때는 회장단이나 담당 관리자에게 등록을 요청해 주시기 바랍니다.

3. 비밀번호 찾기와 로그인 문제 해결

ambassador-hours.vercel.app/login [그림 2] 로그인 화면
화면 설명: 로그인 페이지는 등록된 이메일과 비밀번호로 보안 접속을 진행하며 하단에 비밀번호 재설정 링크를 제공합니다.

3.1 일상 로그인

로그인 화면에서 가입했던 이메일과 비밀번호를 입력하고 로그인 버튼을 누르면 대시보드로 바로 이동합니다.

3.2 비밀번호를 잊어버렸을 때

비밀번호 입력창 아래에 있는 비밀번호를 잊으셨나요 글자를 누르고 가입한 이메일을 입력합니다. 내 메일함으로 비밀번호 재설정 링크가 도착하면 메일 안의 링크를 눌러 새로운 비밀번호를 바로 설정할 수 있습니다.

4. 단원 대시보드 화면 보는 법

대시보드는 로그인하면 가장 먼저 보이는 화면으로 내가 지금까지 모은 총 활동 시간과 현재 심사 현황을 한눈에 보여줍니다.

ambassador-hours.vercel.app/dashboard [그림 3] 단원 대시보드 메인 화면
화면 설명: 상단 공지사항, 총 승인 시간 및 공식과 자율 세부 집계 카드, 대기 요청 건수, 반려 요청 건수 및 신청 내역 필터 목록이 표시됩니다.

4.1 화면 상단과 메뉴

  • 상단 메뉴 바에는 대시보드, 활동 신청, 통합 신청 버튼이 있어 언제든 다른 화면으로 이동할 수 있습니다.
  • 우측 상단에는 알림을 켜고 끌 수 있는 종 모양 아이콘과 내 프로필, 로그아웃 버튼이 있습니다.

4.2 세 가지 현황 카드

  • 총 승인 시간: 관리자가 검토 후 승인을 완료한 진짜 내 누적 시간입니다. 카드 아래쪽에 학교 공식 행사 시간과 부서별 자율 활동 시간이 각각 나누어 적혀 있어 장학금 기준 시간을 얼마나 채웠는지 바로 알 수 있습니다.
  • 대기 중인 요청: 제출을 마쳤지만 아직 관리자가 확인하기 전인 신청서 수입니다. 노란색으로 표시되며 이 상태일 때는 내용을 언제든 고치거나 지울 수 있습니다.
  • 반려된 요청: 사진이 흐리거나 내용이 부족하여 보완이 필요한 신청서 수입니다. 빨간색으로 표시되며 사유를 확인하고 수정해서 다시 제출해야 합니다.

5. 나 혼자 진행한 활동 시간 신청하기

키트 제작, 카드뉴스 만들기, 영상 편집처럼 혼자서 진행한 활동 시간을 올릴 때 사용하는 화면입니다.

ambassador-hours.vercel.app/dashboard/new [그림 4] 개별 활동 시간 신청 화면
화면 설명: 부서별 카테고리 선택, 활동 일자 지정, 가변 시간 최대 제한 유효성 검사, 5MB 증빙 파일 업로드 영역으로 구성된 신청 폼입니다.

5.1 활동 신청서 작성 요령

  1. 활동 카테고리 선택: 내가 속한 부서와 실제 진행한 업무 이름을 선택합니다.
  2. 활동 날짜 선택: 실제 활동을 진행한 날짜를 달력에서 고릅니다.
  3. 시간 확인 및 직접 입력:
    • 정해진 활동은 기본 인정 시간이 알아서 입력됩니다.
    • 기타 자율 활동을 골랐을 때는 0.5시간 단위로 소요된 시간을 직접 입력합니다. 단 과도한 시간 신청을 방지하기 위해 정해진 1회 최대 시간까지만 입력할 수 있습니다.
  4. 활동 내용 작성: 어떤 대상과 어떤 역할을 맡았는지 알기 쉽게 적습니다. 예를 들어 고등학생 35명 대상 전공체험 인솔 및 전자공학과 멘토링 진행처럼 구체적으로 적어야 빠르게 승인받을 수 있습니다.
  5. 증빙 사진 첨부: 활동 중 단복을 입은 내 모습이 보이는 현장 사진이나 완성된 제작물 캡처 사진을 올립니다. 5MB 이하의 사진이나 문서 파일만 등록할 수 있습니다.
  6. 아래쪽의 신청 버튼을 누르면 대기 상태로 등록됩니다.

6. 팀원들과 함께한 활동 한 번에 신청하기

전공체험이나 모의전형 행사처럼 여러 단원이 함께 참여한 활동은 대표자 1명이 모든 참가자의 시간을 한 번에 신청할 수 있습니다.

ambassador-hours.vercel.app/dashboard/bulk [그림 5] 여러 명 통합 신청 화면
화면 설명: 전체 단원 명단 체크박스 다중 선택 기능과 공통 활동 설명 및 공통 증빙 파일을 등록하여 전체 참가자의 대시보드에 일괄 분할 생성하는 화면입니다.

6.1 통합 신청 방법

  1. 상단 메뉴에서 통합 신청을 누릅니다.
  2. 진행한 활동 이름과 날짜를 지정합니다.
  3. 명단에서 함께 활동한 동료들의 이름 옆 체크박스를 누릅니다. 인원이 많으면 전체 선택을 누른 뒤 빠진 사람만 체크를 풀면 빠르고 편합니다.
  4. 대표 사진 1장과 활동 내용을 적고 제출합니다.
  5. 제출이 끝나면 선택된 모든 단원의 대시보드에 각자의 이름으로 신청서가 자동으로 만들어지므로 함께 활동한 다른 단원들이 따로따로 신청할 필요가 없습니다.

7. 제출한 신청 내역 확인 및 수정과 삭제

대시보드 아래쪽에서 내가 올린 활동 카드들을 확인할 수 있습니다.

7.1 상태별 대처 방법

  • 대기중 (노란색): 관리자가 검토하기 전입니다. 카드 오른쪽의 수정 버튼으로 내용을 고치거나 삭제 버튼으로 신청을 취소할 수 있습니다.
  • 승인됨 (초록색): 시간이 정식으로 적립 완료되었습니다. 확정된 데이터이므로 임의로 수정하거나 삭제할 수 없습니다.
  • 반려됨 (빨간색): 보완이 필요한 상태입니다. 카드에 적힌 관리자의 안내 글을 읽고 수정 버튼을 눌러 내용을 채운 뒤 다시 저장하면 대기 상태로 바뀌어 재심사를 받게 됩니다.

8. 반려되었을 때 대처하고 다시 제출하는 방법

신청이 반려되더라도 당황할 필요 없이 아래 순서대로 수정하면 바로 승인을 받을 수 있습니다.

  1. 대시보드 목록에서 반려됨 탭을 누릅니다.
  2. 반려된 카드 안에 빨간 글씨로 적힌 반려 사유를 꼼꼼히 확인합니다. 예를 들어 단복 착용 사진이 보이지 않습니다처럼 보완할 점이 적혀 있습니다.
  3. 카드의 수정 버튼을 누르면 입력창이 다시 열립니다.
  4. 관리자가 지적한 사진을 알맞은 사진으로 교체하거나 부족했던 설명 글을 보완합니다.
  5. 저장 버튼을 누르면 즉시 대기중 상태로 바뀌며 관리자가 다시 심사하게 됩니다.

9. 공지사항 확인과 스마트폰 푸시 알림 켜기

9.1 중요 공지 확인

대시보드 위쪽에 있는 공지사항 게시판에서 회장단과 관리자의 전달사항을 확인합니다. 핀 모양 아이콘이 붙은 글은 가장 중요한 공지이므로 활동 시간 마감 일정 등을 꼭 읽어보시기 바랍니다.

9.2 실시간 알림 켜기

상단 메뉴 우측의 종 모양 아이콘을 누르고 브라우저 알림을 허용해 두면 내가 올린 신청서가 승인되었을 때 축하 알림이 오고, 반려되었을 때는 사유와 함께 바로 스마트폰 화면에 알림이 떠서 빠르게 대처할 수 있습니다.

1. 관리자 권한 및 기본 화면 안내

광운알리미 시간 관리 시스템은 홍보대사 단원들이 제출한 활동 시간을 공정하게 심사하고, 학기 말 장학금 지급 서류로 손쉽게 변환할 수 있도록 제작된 전용 관리 도구입니다.

관리자 계정으로 로그인하면 상단 메뉴 바에 일반 단원용 메뉴 외에 관리자 전용 메뉴 3가지가 나타납니다.

  • 승인 대기열: 단원들이 제출한 신청서를 검토하여 승인하거나 반려하고, 과거에 승인했던 내역까지 필요시 삭제하여 시간을 차감할 수 있는 심사 화면입니다.
  • 카테고리 설정: 공식 행사 및 각 부서별 과업의 인정 시간과 1회당 최대 인정 한도를 관리하는 기준 설정 화면입니다.
  • 사용자 관리: 신입 단원 초대, 차기 회장단 관리자 권한 부여, 단원별 세부 활동 실적 차트 확인 및 결재용 엑셀 다운로드를 수행하는 관리 화면입니다.

2. 승인 대기열에서 신청서 심사하고 승인하기

단원들이 활동을 마친 뒤 등록한 신청서를 꼼꼼히 확인하고 정식 시간으로 확정하는 과정입니다.

ambassador-hours.vercel.app/admin [그림 6] 승인 대기열 심사 관제 화면
화면 설명: 대기 중인 요청, 승인된 요청, 반려된 요청 상태 탭과 통합 신청 그룹 카드 및 일괄 승인, 일괄 반려 버튼이 배치된 관제 화면입니다.

2.1 화면 상태 탭 활용

  • 대기 중인 요청: 아직 심사하지 않은 신청서 목록입니다. 기본으로 열리는 화면이며 매일 또는 매주 주기적으로 확인하여 승인 처리를 진행합니다.
  • 승인된 요청: 이미 검토를 마친 과거 승인 완료 목록입니다.
  • 반려된 요청: 서류나 사진 미비로 단원에게 수정을 요청해 둔 목록입니다.

2.2 심사 시 확인해야 할 핵심 기준

  1. 날짜와 활동 시간: 실제 행사가 진행된 날짜가 맞는지, 자율 활동인 경우 적절한 시간이 청구되었는지 확인합니다.
  2. 활동 내용 서술: 구체적으로 어떤 학교를 대상으로 어떤 멘토링이나 제작을 수행했는지 확인합니다.
  3. 증빙 파일 확인: 첨부된 파일 이름을 누르면 사진이나 문서 원본이 열립니다. 단복이나 명찰을 착용하여 본인임이 분명히 확인되는지 점검합니다.

2.3 일괄 승인과 실시간 알림 발송

  • 여러 단원이 함께 신청한 통합 신청 건은 카드가 한 장으로 묶여 표시되며, 참여 단원 명단 버튼을 눌러 전체 참가자를 확인할 수 있습니다.
  • 내용에 이상이 없으면 초록색 일괄 승인 버튼을 누릅니다.
  • 승인 버튼을 누르는 즉시 단원의 누적 시간에 해당 시간이 즉시 합산되며, 단원의 스마트폰으로 활동 시간이 승인되었다는 축하 알림이 즉시 전송됩니다.

3. 잘못 작성된 신청서 반려하기와 친절한 사유 작성 요령

증빙 사진이 다른 사진이거나 내용이 부실할 때는 반려 기능을 통해 단원에게 수정을 요청합니다.

  1. 해당 카드의 빨간색 반려 버튼을 누르면 사유를 적는 입력창이 나타납니다.
  2. 단원이 어떤 부분을 고쳐야 하는지 쉽게 알 수 있도록 구체적이고 친절하게 적어줍니다. 예를 들어 행사 현장에서 단복을 착용한 본인 사진이 누락되었습니다. 단복 착용 사진으로 교체해 주시면 바로 승인해 드리겠습니다처럼 정확한 가이드를 제공합니다.
  3. 확인을 누르면 해당 사유가 단원의 스마트폰 알림으로 즉시 전송되고, 단원은 대시보드에서 사유를 확인한 뒤 내용을 수정하여 다시 제출하게 됩니다.

4. 이미 승인된 과거 활동 시간 삭제 및 자동 차감 관리

실수로 잘못 승인했거나 뒤늦게 중복 청구 사실이 확인된 경우, 이미 승인 처리가 끝난 시간이라도 언제든 취소하고 삭제할 수 있습니다.

4.1 승인된 내역 삭제 절차

  1. 승인 대기열 화면 상단에서 승인된 요청 탭을 클릭합니다.
  2. 삭제할 활동 카드를 찾아 오른쪽 아래의 빨간색 삭제 버튼을 누릅니다.
  3. 삭제 확인 창에서 확인을 누르면 데이터가 안전하게 삭제됩니다.

4.2 삭제 시 시스템 내부 자동 반영

  • 해당 신청서가 완전히 삭제되는 즉시 단원의 총 승인 시간과 누적 인정 시간에서 해당 활동 시간이 실시간으로 자동으로 빠집니다.
  • 통합 신청으로 승인되었던 단체 활동을 삭제하는 경우에도 그 활동에 들어있던 모든 단원의 누적 시간에서 알아서 함께 차감되므로 관리자가 계산기를 두드리며 수동으로 뺄 필요가 없습니다.

5. 활동 카테고리 신설 및 1회 최대 시간 규정 설정

광운알리미의 공식 행사와 5개 부서별 세부 활동 목록을 등록하고 인정 시간을 조정하는 화면입니다.

ambassador-hours.vercel.app/admin/categories [그림 7] 카테고리 및 규정 설정 화면
화면 설명: 부서별 탭 필터와 활동 유형, 인정 시간, 1회당 최대 제한 시간 설정 및 활성화 토글 스위치 관리 화면입니다.

5.1 부서별 탭 필터

화면 윗부분에 공식 행사, 미디어홍보부, 전공체험부, 전략기획부, 임원진 및 부장, 신입기수, 기타 자율 탭이 있어 부서별 항목을 빠르게 골라볼 수 있습니다.

5.2 새 카테고리 추가 요령

  1. 우측 상단의 새 카테고리 추가 버튼을 누릅니다.
  2. 활동 이름과 공식인지 자율인지 유형을 선택하고 담당 부서를 지정합니다.
  3. 기본 인정 시간을 정해줍니다. 정해진 시간이 있는 일반 활동은 0.5시간부터 5.0시간까지 입력하고, 단원이 직접 시간을 적어야 하는 활동은 0시간으로 설정합니다.
  4. 최대 제한 시간 설정: 단원이 직접 시간을 적는 기타 자율 활동의 경우 과도한 시간 청구를 방지하기 위해 1회당 최대 4.0시간까지만 신청할 수 있도록 상한선 숫자를 적어둡니다. 이렇게 설정해 두면 단원이 그 이상의 숫자를 입력하고 신청하려 해도 시스템에서 자동으로 막아줍니다.
  5. 활성화 스위치: 당분간 쓰지 않는 활동은 스위치를 꺼두면 기존 이력은 그대로 보존되면서 단원 신청 화면에서만 보이지 않게 숨겨집니다.

6. 신규 단원 초대와 관리자 권한 부여 및 인계

새로 선발된 신입 단원을 등록하고, 차기 회장단에게 관리자 권한을 넘겨주는 공간입니다.

ambassador-hours.vercel.app/admin/users [그림 8] 사용자 관리 및 정산 엑셀 내보내기 화면
화면 설명: 신규 단원 초대 폼, 단원별 공식과 자율 누적 시간 요약, 카테고리별 세부 수행 실적 프로그레스 바 차트 및 정산 엑셀 다운로드 버튼이 배치된 화면입니다.

6.1 신입 단원 일괄 초대

  1. 사용자 관리 화면 위쪽의 초대 폼에 신입 단원의 기수 및 이름과 공식 이메일을 적습니다. 예를 들어 16기 홍길동과 학교 이메일을 입력합니다.
  2. 초대 버튼을 누르면 사전 등록이 완료됩니다.
  3. 단원이 그 이메일로 회원가입을 마치면 바로 활성 상태로 바뀌며 활동을 시작할 수 있습니다.

6.2 차기 회장단 관리자 권한 부여

  1. 단원 목록에서 권한을 줄 단원의 카드를 찾습니다.
  2. 카드에 있는 역할 변경 버튼이나 관리자 지정 버튼을 클릭합니다.
  3. 클릭 즉시 일반 단원에서 관리자로 등급이 올라갑니다.
  4. 권한을 받은 단원은 다시 로그인할 필요 없이 즉시 화면 상단에 승인 대기열, 카테고리 설정, 사용자 관리 메뉴가 나타나 함께 심사 업무를 볼 수 있습니다.
  5. 임기가 끝난 뒤에는 같은 버튼을 눌러 다시 일반 단원으로 되돌리면 됩니다.

7. 단원별 활동 실적 분석 그래프 확인

단원 목록에서 각 단원의 카드를 누르면 아래쪽으로 세부 실적 목록이 펼쳐집니다.

  • 해당 단원이 전공체험이나 모의전형 행사를 몇 번 나갔고, 카드뉴스를 몇 개 제작했는지 항목별 횟수와 시간이 한눈에 보입니다.
  • 각 활동별 비중이 막대그래프로 보기 쉽게 표시되어 특정 단원이 특정 부서 일에만 치우치지 않았는지 파악하고 업무를 고르게 배분하는 데 큰 도움이 됩니다.

8. 학기말 장학금 정산 엑셀 파일 한 번에 다운로드하기

학기 말에 장학금 지급 결재를 올릴 때 가장 유용하게 쓰는 기능입니다.

8.1 추천하는 학기말 정산 순서

  1. 대기 목록 일괄 심사: 승인 대기열로 가서 아직 처리하지 않은 대기 중인 신청서들을 모두 확인하고 승인하거나 반려 처리합니다.
  2. 정산 엑셀 파일 다운로드: 사용자 관리 화면으로 이동하여 오른쪽 위의 정산 데이터 엑셀 다운로드 버튼을 누릅니다.
  3. 정산 내역 확인: 전체 단원의 기수, 이름, 이메일, 공식 활동 시간, 자율 활동 시간, 총 합계 시간이 깔끔하게 정리된 엑셀 파일이 즉시 내려받아집니다.

9. 상단 고정 공지사항 등록 및 푸시 알림 안내

  • 대시보드 공지 보드에서 공지 작성 버튼을 눌러 전체 단원에게 알릴 공지사항을 작성합니다.
  • 꼭 읽어야 하는 중요한 공지는 상단 고정 체크를 해두면 새로운 글이 등록되어도 항상 맨 위에 핀으로 고정됩니다.
  • 관리자가 승인이나 반려 버튼을 누를 때마다 단원 스마트폰으로 실시간 알림이 발송되므로 단원들이 신청 결과를 빠르게 확인할 수 있습니다.
